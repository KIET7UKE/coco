## Vercel Alternatives: where Coco changes the comparison

Vercel is the platform most frontend teams mean by "just deploy the Next.js app." Previews per pull request, a global cache, and serverless functions are the product. It is excellent at the edge of a web app and awkward as a home for a long-running API, a queue worker, a database, or a GPU. Function duration, memory, and bandwidth become the bill. A backend that holds a websocket or a 20-minute job does not belong in a serverless function. Keep the frontend on Vercel if that workflow is paying for itself, and run the processes that need a real CPU on a cloud built for them.
